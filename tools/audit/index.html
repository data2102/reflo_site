손으로 만드는 이 파일,
자동화될까요?

지금 손으로 만드는 완성된 파일을 넣어 보세요. 어떻게 만들어졌는지 읽고, 자동화가 될지 먼저 말씀드려요. 원본까지 넣으면 더 정확해요. 합계가 틀릴 자리도 같이 찾아요.

완성된 파일만 넣어도 자동화될지 볼 수 있어요. 원본까지 넣으면 둘이 어떻게 이어지는지 보고 더 정확하게 말씀드려요.

이 화면에 넣은 파일은 브라우저 안에서만 읽어요. 어디로도 보내지 않아요.

그래도 이름·연락처·주민번호·계좌 같은 개인정보는 지우고 넣어 주세요. 열 이름과 표 모양만 있으면 충분해요.

파일이 못 알려 주는 것 네 가지만 골라 주세요

자동화 전에 손볼 곳
이 화면이 본 것과 보지 않은 것
  • 본 것: 고른 시트의 머리글과 열, 수식으로 계산된 칸과 손으로 넣은 칸, 다른 시트나 다른 파일을 가리키는 수식, 파일 안에 원본처럼 보이는 시트, 합계가 틀릴 자리 다섯 가지. 받은 자료를 넣었다면 겹치는 열과, 합계가 같은 열.
  • 보지 않은 것: 숫자가 실제로 어디서 오는지, 받는 자료가 매번 같은 모양인지, 중간에 사람이 판단하는 곳. 그래서 이 판정은 어림이에요. 확정은 검토에서 말씀드려요.
  • 다른 파일을 가리키는 수식이 있어도 그 경로는 화면에도, 메일 본문에도 옮기지 않아요.
  • 아무것도 고치지 않아요. 넣으신 파일은 그대로예요.

숫자를 다 맞게 넣고도 합계가 틀리는 자리

엑셀은 틀렸다고 알려 주지 않아요. 조용히 건너뛰거나, 조용히 두 번 더해요. 자동화할 때도 이 자리부터 손봐요.

소계 줄을 같이 더해요

내려받은 파일 사이사이에 「소계」「합계」 줄이 있으면, 범위를 잡아 더할 때 그 줄까지 들어가요. 합계가 두 배 가까이 부풀어요.

글자가 든 금액이 빠져요
